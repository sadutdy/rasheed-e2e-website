# Partner logos

Put the official logo files in this folder. The site shows a plain text name for any file that is missing.

Expected filenames (SVG preferred; if you only have PNG, change the extension in the `PARTNERS` list in `site/index.html`):

- makemytrip.svg
- easemytrip.svg
- cleartrip.svg
- akbar-travels.svg
- alhind-travels.svg
- riya-connect.svg
- irctc.svg
- unimoni.svg
- abhibus.svg
- bank-of-baroda.svg

Get each logo from the partner's portal or brand kit. Do not recolour or redraw them. Keep each file under about 50 KB.
